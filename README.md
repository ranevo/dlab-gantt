# dlab-gantt

DLab 프로젝트 관리 솔루션을 위한 초기 프로토타입입니다. Windows 11 환경에서의 사용을 상정하며, 프런트엔드 UI부터 백엔드 및 MySQL 연동까지 확장할 계획입니다. 현재는 사용자 경험을 미리 확인할 수 있는 간트 기반 GUI를 먼저 구성했습니다.

## 프로젝트 구조

```
.
├── backend/        # 백엔드 서비스 초기화 예정 (Express, NestJS, Spring 등 자유롭게 확장)
├── frontend/       # 간트 UI가 구현된 정적 프로토타입
├── README.md
└── .gitignore
```

## 프런트엔드 프로토타입 미리보기

`frontend/index.html`을 브라우저에서 직접 열면 아래 기능을 확인할 수 있습니다.

- **3분할 레이아웃**: 좌측 프로젝트 트리, 중앙 간트 차트, 우측 메모 & TODO 패널
- **트리 & 간트 동기화**: 트리를 접고 펼치면 간트의 태스크 막대도 같은 계층 구조로 숨겨지거나 표시됩니다.
- **타임라인 스크롤 연동**: 간트 본문을 좌우로 스크롤하면 날짜 헤더도 함께 움직여 일정 기준을 유지합니다.
- **TODO & 메모 패널**: 진행 메모 작성과 간단한 체크리스트 추가/완료를 바로 관리할 수 있습니다.
- **오늘 표시 및 통계**: 오늘 날짜 라인과 마감 임박/지연/완료 건수를 확인할 수 있습니다.

> 💡 추후에는 프런트엔드를 React/Vue 등으로 옮겨가고, 백엔드 API 및 MySQL과의 데이터 연동을 통해 실제 프로젝트 정보를 불러오도록 확장할 예정입니다.

## 다음 단계 제안

1. **백엔드 스택 결정 및 초기화**: Express + TypeScript, NestJS, Spring Boot 등 팀 선호에 맞게 REST API 혹은 GraphQL 서버를 구성합니다.
2. **MySQL 스키마 설계**: 프로젝트, 태스크, 메모, 체크리스트를 저장할 스키마를 설계하고 마이그레이션 도구를 도입합니다.
3. **API 연동**: 현재 정적으로 주입한 더미 데이터를 API 호출로 대체하고, 트리 및 간트 UI와 실시간으로 동기화합니다.
4. **상호작용 보강**: 드래그로 일정 변경, 간트 줌, 필터링 등 고급 기능을 추가합니다.

프로토타입을 통해 화면 구성을 빠르게 합의하고, 이후 백엔드/데이터 연동 작업으로 확장해 나가면 됩니다.
